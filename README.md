## ▶️ Como Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/Iriscalixt0/Portfolio-Profissional.git
```

2. Acesse a pasta:

```bash
cd portfolioFull
```

3. Abra o arquivo:

```bash
index.html
```

✔️ Não é necessário instalar dependências
✔️ Tailwind utilizado via CDN
